# 01 — Custom Tags Management (Create, Edit, Delete, Color Picker)

**What to build:**
Enable users to create new custom tags with personalized names and color swatches via the sidebar `+` button, right-click on any tag to rename or change its color, and delete tags with automatic cleanup from all file associations.

**Blocked by:**
None — can start immediately.

**Status:** ready-for-agent

- [x] Sidebar tags header displays a `+` button that opens a Fluent tag creation modal.
- [x] Color picker provides 8 distinct Fluent pastel and accent swatches with custom name input.
- [x] Right-clicking any custom tag in the sidebar opens a context menu with "Edit Tag" and "Delete Tag".
- [x] Deleting a tag prompts a Fluent confirmation dialog and removes the tag from all tagged files in store.
- [x] File context menus and preview panel dynamically list all active custom tags.
